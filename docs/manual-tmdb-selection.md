# 手动指定 TMDB 条目

在「手动处理」输入文件路径后，可填写 TMDB 编号并选择电影或电视剧。编号留空时维持自动识别。编号为作品的电影 ID 或剧集 ID，不是单集的 TMDB ID。

「预览重命名」「验证刮削」「处理选中的文件」共用本次填写的条目。批量选中的所有文件会使用同一作品编号；不同作品应分开提交。季号和集号仍从各自文件名及路径解析。

显式指定的编号不会被文件名中的其他编号、手动规则或名称搜索覆盖。条目查询失败时处理失败，不回退到名称搜索，也不把该任务加入只包含文件路径的自动重试队列。它不修改 INI、数据库配置或本地文件名，只作用于本次提交；重新提交时需保留选择。

## API

`POST /api/manual/preview`、`/validate`、`/process` 支持可选的 `tmdb_id`（正整数）及 `media_type`（`movie` 或 `tv`）。填写编号时类型必填。

批量接口 `POST /api/manual/process-batch` 保留旧的路径数组请求，也接受对象：

```json
{"file_paths":["/input/Show.S02E03.mkv"],"tmdb_id":1399,"media_type":"tv"}
```

预览、验证和入队使用同样的选择参数；已经排队或处理中的文件会跳过，避免改写正在执行的任务。
