# 上传失败与重试状态

任务列表按「完整文件路径、文件大小、修改时间、上传目标组合」汇总，同一文件版本的多次失败不会重复占行。每次结果仍写入原始 `task_history`，通过 `upload_attempt` 关联到 `upload_task`；原始历史不会被删除。

「失败与重试」提供未解决、已解决、全部失败历史筛选。提交重试仅进入等待/处理中/上传中，全部配置的上传目标最终成功后才标记「重试成功 · 已解决」。已完成列表与最近活动也会显示此标记，仪表盘分别统计未解决任务和重试已解决任务。可打开「尝试历史」查看每次错误和结果时间。清除只隐藏失败汇总，不代表解决，也不删除尝试历史。

重试按任务 ID 提交，保留手动指定的 TMDB 信息；文件内容版本或目标组合变化时拒绝覆盖原任务，应重新手动处理为新任务。重复点击或文件不存在不会假报已提交。服务重启后，中断的任务恢复为失败，等待重新提交。

升级会幂等导入历史：旧版没有记录目标和文件版本，只能按完整路径汇总，页面明确显示「历史记录（目标未知）」。不能据此区分过去曾在同路径替换的文件或不同上传目标。手动重试旧记录时才将其绑定到当前文件与目标；所有旧明细均保留。
