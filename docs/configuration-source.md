# 配置来源

常规业务配置以 `config.ini` 为准。网页配置管理中的处理配置、手动规则、字幕组映射等入口编辑 INI；`delete_after_upload`、`upload_targets` 和 `max_upload_workers` 不再提供数据库编辑入口。

LLM 提供商保持原行为：优先读取数据库中的启用记录，没有可用记录时回退到 INI 的 `llm_provider_N`。网页保留 LLM 提供商的数据库编辑入口；`llm_fallback` 总开关等仍在 INI 中设置。

历史数据库中的手动规则、字幕组映射和运行时配置保留，不删除、不覆盖。相关旧配置 API 返回 HTTP 409，避免缓存的旧网页继续写入无效副本。首次启动不再将这些重复配置导入数据库；LLM 提供商和登录账号的初始化保持可用。账号、API Key、任务历史功能继续使用数据库。

本次仅明确配置来源并屏蔽重复入口，不改变正在运行的组件的配置加载时机，也不把“已保存”当作热更新成功。
