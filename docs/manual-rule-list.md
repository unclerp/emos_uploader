# 手动规则列表

在「配置管理 → 手动规则」点击「新增规则」，填写文件名匹配关键词、TMDB 编号和电影/电视剧类型。关键词留空表示匹配所有文件。规则按从上到下执行，重叠时后面的指定信息可以覆盖前面的；匹配词相同或互相包含时页面会提示。

每一行可以独立启用、停用、上移、下移、编辑或删除。最上方「启用手动规则」控制整个规则引擎。修改完成后点击「保存配置」，保存成功后自动应用。停用状态、列表顺序与高级规则都会保存在 INI 中。

「高级文本模式」支持原有 DSL，每行一条；以 `# disabled: ` 开头的行表示停用规则。切回列表时，简单 TMDB 规则自动转换为表单，替换、屏蔽词、定位等规则保留原文，不丢弃未知规则。

INI 原有 `rules` 和 `ruleN` 写法可继续读取。保存时 `_rules_json` 保留完整有序列表和启停状态，同时 `ruleN` 仅导出启用的规则以兼容旧版读取。读取新版列表时不重复导入 `ruleN`。
